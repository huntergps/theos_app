## Bloque mínimo reproducible

El dry-run local de `Erp2HarnessConfig.fromEnvironment(Platform.environment)`
reporta exactamente `explicit write sentinel is missing` y
`explicit run sentinel is missing`; ya no exige `MIXED_PAYMENT_WIZARD_ID` ni
ningún ID transient FSC/mixto ni identidad fiscal offline (`sequential`, fecha
de emisión o access key) para el recorrido mixto ya facturado. La integración
permanece omitida y no se ejecutó el stage remoto mutante.

La auditoría estructural del backend añade un bloqueo independiente para el
E2E mixto: `action_apply_existing_invoice()` sólo genera despacho para
`is_cash and not is_credit`; una venta mixta (`is_credit=True`) queda sin
`stock.picking` después del cobro nativo. El harness no puede suplirlo con
`action_regenerar_despacho_contado` ni con una acción de stock inventada; se
requiere corregir/verificar esa regla backend antes de ejecutar los cuatro
flujos completos.
