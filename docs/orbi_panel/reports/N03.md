# N03 · Adaptador de notificaciones del sistema

Se implementó `SystemNotificationPresenter` con plugin inyectable y bridge real
para `flutter_local_notifications` 22.3.0. Consume los tipos canónicos de
`theos_pos_core` (`NotificationScope`, `NotificationTarget`,
`NotificationCapabilities`, `NotificationChannel`) y usa solamente
`SystemNotificationRequest` como DTO específico de presentación. Incluye
capacidades por plataforma, permiso únicamente mediante
`requestPermissionFromUserAction`, `showOrReplace` y cancelación aislada al
scope activo; ambas operaciones requieren inicialización exitosa.

`SystemIdPort` es solo una dependencia del registro persistente N02: no asigna,
no usa `hashCode` y no duplica almacenamiento. El payload es JSON mínimo de
versión, entrada opaca, scope, partición y revisión; no contiene URL, comandos,
secretos ni importes. Web/Linux/Windows no prometen scheduling/background/push.

El registro installation-wide de N02 conserva los IDs entre reinicios y scopes;
el presenter solo consume su lookup, sin contador local.

La inicialización Android usa el recurso existente `@mipmap/ic_launcher`; no se
añadieron shells ni permisos. La revisión de shells confirma que V02 aún debe
definir permisos de notificación Android/iOS/macOS y validar package identity de
Windows; Linux/Web quedan limitados a show/cancel según capacidades del plugin.

Android quedó con desugaring Java 17 obligatorio (`isCoreLibraryDesugaringEnabled`,
`desugar_jdk_libs:2.1.4`) y `compileSdk = 37` por el requisito efectivo de
`flutter_secure_storage`; supera el mínimo 35. `flutter build apk --debug`
terminó correctamente y generó `build/app/outputs/flutter-apk/app-debug.apk`.

Verificación: `flutter analyze lib/src/notifications/system_notification_presenter.dart
test/notifications/system_notification_presenter_test.dart` correcto, sin issues;
`flutter test test/notifications` correcto, 9 pruebas N02/N03 de runtime. La
prueba visible del SO en cada plataforma queda pendiente para V02; los tests
focales usan plugin inyectado y no simulan push ni background.
