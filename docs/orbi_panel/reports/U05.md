# U05 — Editor de venta adaptable

El editor comparte `SaleDraftSnapshot` entre mostrador y consultiva. El término de pago se representa por cuotas y `classification` consume `SaleDraftPayload.classification` exportado por F05 a través de `orbi_runtime`; no existe selector de tipo de venta. `SharedPreferencesSaleDraftStore` conserva el borrador por `scopeKey` y permite restaurarlo tras reinicio de proceso. `F07SaleEditorPort` adapta el borrador a `SaleCommandPort`; el fallback productivo es explícitamente no configurado y nunca acepta/encola.

La pantalla recibe `SaleCatalogPort` para términos locales (sin opciones hardcodeadas), usa `OrbiReactiveTextField` con `Validators.required`, y muestra líneas con cantidad, precio, descuento, impuesto y total calculados por el puerto/core. El mismo borrador sirve a mostrador y consultiva; el layout compacto prioriza lista/teclado y el amplio separa formulario/resumen.

La integración U03 permite inyectar `CatalogController<String>` reales para cliente y producto mediante `EntityPicker`; productos seleccionados se agregan al mismo borrador, con quitar y cantidad +/- sin recalcular importes en widget. Almacén se muestra solo cuando la capacidad del scope lo permite. El editor conserva controllers/dirty al redimensionar.

Se cablearon `/sales/counter` y `/sales/consultive` al mismo controlador, store y puerto; la política de acceso cubre ambas rutas. El editor conserva estado al resize, bloquea doble submit y muestra el bloqueo comercial/acción pendiente.
