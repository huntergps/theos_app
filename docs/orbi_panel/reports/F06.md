# F06 · autenticación web/offline — W01 implementado

La PWA no almacena contraseñas ni claves API en JavaScript. Odoo sirve Orbi
bajo `/orbi/` con `auth='user'`; el navegador reutiliza exclusivamente la
cookie HttpOnly de la sesión Odoo y obtiene su alcance mediante
`GET /orbi/bootstrap`.

El bootstrap sólo expone base, usuario actual, compañía efectiva, compañías
permitidas, capacidades, una huella de alcance y el token CSRF. El cliente SDK
usa después el transporte estándar same-origin
`/web/dataset/call_kw/<modelo>.<método>`. Si la sesión caduca se redirige al
login normal de Odoo y nunca aparece un formulario web que prometa autenticar
con una API key efímera.

El bundle release se genera con `--base-href /orbi/` y se instala en
`l10n_ec_collection_box_pos/static/orbi`. Los archivos de entrada, bootstrap,
worker y aplicación usan `no-store`; sólo recursos versionables de motor e
iconos reciben caché inmutable. La sesión nativa con credencial segura sigue
siendo independiente.
