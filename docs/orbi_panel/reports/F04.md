# F04 · C02/C03 contracts

Materialized pure Dart contracts for capabilities, stable order queries, typed
command envelopes, and generic `OperationOutcome<TBusinessState extends Enum>`.
Existing `SaleOrderState` and collection `SessionState` are reused directly; no
parallel business enum, SaleOrder duplicate, fiscal formula, Odoo call, widget,
Riverpod `Ref`, or artificial sale-type field was introduced.

Constructors validate IDs, revisions, limits, command identifiers, versions and
date ranges at runtime. Collection/map/list inputs are defensively copied and
exposed read-only. Commands remain marker envelopes; F05 supplies operation
inputs and financial payloads.

The core currently has no `Money` value object, so commands intentionally carry
only the common scope/command/target envelope; amount-bearing fields remain for
the existing domain models/adapters to supply.

Validation: `dart format`, `dart analyze`, and the focal operation contract tests.
